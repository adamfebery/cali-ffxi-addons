# bluexport

Writes your Blue Mage state to a text file, so you can plan sets outside the game:

- every blue spell you know
- the spells you have set now (only readable while BLU is your main job)
- your active job traits
- your BLU job points

It writes to `data/<Character>_blu.txt`.

**Load:** `//lua load bluexport`

## Commands
- `//bluexport` (or `//bluex`): write the file. Be on BLU to capture the set spells.
